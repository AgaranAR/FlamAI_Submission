# AI Team Intern Assignment — The Audit

This repository contains my submission for the AI Team Intern Assignment (The Audit).

## Repository Structure

- `NOTEBOOK.md`: A chronological lab notebook detailing my hypothesis, experiments, dead ends, and results throughout the assignment.
- `AI_USAGE.md`: A summary of how AI tools were used during the assignment, including surprising findings and corrected hallucinations.
- `partA/`: The tokenizer audit. Contains the eval corpus, the corrected tokenizer script (`fertility_fixed.py`), the evidence for code bugs (`bugs_and_evidence.md`), and the final routing memo (`A1_A3_A4_Analysis.md`).
- `partB/`: Capacity reconciliation. Contains the math and logs for KV-cache bytes/token, maximum concurrent sequences, and the throughput anomaly (`calculations.md`).
- `partC/`: The strategic decision memo for generating casual-tone outputs under constrained reviewer bandwidth (`memo.md`).
